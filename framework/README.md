# WebMVC.js

A modern JavaScript framework for building **single-page applications** with a clean **Model–View–Component** (MVC) architecture and **JSX-like syntax** — no virtual DOM diffing, just simplicity and speed.

## ✨ Features

- 🧩 **Component-based** UI architecture
- 🧠 **Model-driven state management** (Observer-style)
- ⚡ **JSX support** (via a lightweight `h()` function)
- 🔁 **Automatic re-render on model changes**
- 🧼 **Minimal runtime**, no dependencies
- 🛠 Built with **Vite**

## 🚀 Getting Started

### 1. Clone this repo

```bash
git clone https://github.com/congjuny/webmvc.js.git
cd webmvc.js/example-app
npm install
npm run dev
```
